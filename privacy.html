Privacy Policy — SIARAN

Last updated: 2026-11-08

SIARAN is a private tool operated by me for my own YouTube channel. It is not offered to the public and no data is sold or shared.

What SIARAN accesses through Google APIs

Using the YouTube Data API and YouTube Analytics API with OAuth scopes youtube.upload, youtube.readonly and yt-analytics.readonly, SIARAN accesses only my own channel's data:

  • videos I upload, plus their titles, descriptions, tags and status;
  • my channel's public statistics (views, likes, comments);
  • my channel's aggregate analytics reports (impressions, click-through rate, average view duration, subscriber gains).

How that data is handled

  • All data stays on my own machine/server. Nothing is sent to third parties.
  • OAuth credentials are stored in a local file with restricted permissions (chmod 600) and are never committed to source control.
  • Analytics data is kept locally only to report performance to me.
  • No user tracking, no cookies, no advertising identifiers.

Deleting access

I can revoke the app's access at any time from my Google Account (Security → Third-party apps with account access) or by deleting the local credential file, which also removes the locally stored reports.

Contact

Questions: reply via the support email listed on the Google OAuth consent screen.
